# Data Science Journey

A hands-on learning repository documenting my progress in **Python-based data analysis, data cleaning, exploratory data analysis (EDA), and visualization**. It contains topic-wise notebooks, exercises, and small datasets that I use to practise core data-science workflows.

## Learning roadmap

| Section | Topics and practice |
|---|---|
| [02 - NumPy](02_NumPy/) | Array creation, operations, indexing, slicing, and 2D arrays |
| [03 - Pandas](03_Pandas/) | Series, DataFrames, missing values, grouping, aggregation, joins, concatenation, and pivot tables |
| [04 - Visualization](04_Visualization/) | Matplotlib fundamentals and Seaborn categorical and distribution plots |
| [05 - Projects](05_Projects/) | Anime dataset exploration and country data analysis |
| [Datasets](datasets/) | CSV files used by the notebooks |
| [Visual assets](assets/images/) | Images used in the repository |

## Recommended learning sequence

1. Build a foundation in NumPy arrays and vectorized operations.
2. Work with Pandas Series and DataFrames.
3. Practise cleaning, transforming, and validating data.
4. Explore data using grouping, aggregation, joins, and pivot tables.
5. Communicate findings through Matplotlib and Seaborn.
6. Revisit the project notebooks and explain the insights, assumptions, and limitations.

## Getting started

Clone the repository and install the commonly used libraries:

```bash
git clone https://github.com/Aayush-Bajaj/DATA_SCIENCE_JOURNEY.git
cd DATA_SCIENCE_JOURNEY
pip install numpy pandas matplotlib seaborn jupyter
```

Open the notebooks in Jupyter Notebook, JupyterLab, or Google Colab. Some notebooks use local CSV paths; if you run them outside this repository layout, update the paths to the corresponding files in `datasets/`.
